Quickstart Guide

Jev Judge Setup

github.com/xolotlwastaken/jev-judge
How to clone the repository, connect the Jev model via OpenRouter, load the Chrome extension, and run real-time post classification on X.
01 Clone the repository
Clone the project and install the backend dependencies: 
git clone https://github.com/xolotlwastaken/jev-judge.git
cd jev-judge/server
npm install
02 Get an OpenRouter API key
TypeSafe AI's Jev model is hosted on OpenRouter as ~typesafe/jev-latest. You can access it directly with no waitlist:
  1. Sign in at openrouter.ai and go to openrouter.ai/keys.
  2. Click Create Key, name it jev-judge, and copy the key (sk-or-v1-...).
  3. (Optional) Add $1 credit. At $0.042 / 1M input tokens, $1 covers over 20,000 tweets.
Note: If you leave the key blank, the backend automatically runs in offline demo mode with simulated classifications for testing.
03 Configure `.env` and start the server
Copy the example environment template inside the server/ directory: 
cp .env.example .env
Open server/.env and set your key: 
OPENROUTER_API_KEY=sk-or-v1-your_actual_key_here
PORT=8787
DEBUG=false
Start the backend: 
npm run dev
✓ Terminal will display: Jev Judge Backend running on http://localhost:8787 · Active Provider: OpenRouter (Jev)

04 Load the Chrome extension
Load the unpacked extension folder into Chrome:
  1. Open Google Chrome and navigate to chrome://extensions.
  2. Turn on Developer mode using the toggle in the top-right corner.
  3. Click Load unpacked in the top-left toolbar.
  4. Select the extension/ folder inside the cloned jev-judge directory.
05 Open X and test in real time
Go to x.com in Chrome (or refresh any tab). As you scroll through your feed:
  • A floating JEV HUD pill appears in the bottom-right corner tracking judged posts and spend in real time.
  • Posts in your viewport flash ◆ JEV JUDGING... and resolve into one of 4 categories within ~200ms:
Category Visual Treatment What It Classifies
BREAKING Neon green strobe badge + green border glow Major model launches, releases, announcements
GOLDEN NUGGET Golden shimmering badge + yellow accent border Practical tutorials, code, workflows, benchmarks
MEH Subtle grey badge + grey left border Routine thoughts, casual banter, everyday chatter
AI SLOP Permanent animated meme stamp + red siren border Recycled threads, hype bait, engagement farming
Click the extension icon in the toolbar to see cumulative counts, total dollar spend, or click Reset session to wipe cached stamps and start fresh.
06 Quick tips & troubleshooting
  • Badges say UNAVAILABLE? The backend must be running on port 8787. Verify with curl http://localhost:8787/health.
  • Made changes to code or styles? Go to chrome://extensions, click reload (↻) on Jev Judge, and refresh X (Cmd + Shift + R).
  • Recording a demo? Position X on the left side of your screen and the terminal on the right. Your audience can watch classifications and costs log simultaneously.
