⚡ Jev Judge Setup Guide

Complete guide to clone the repo, configure the Jev API key via OpenRouter, load the Chrome extension, and classify X (Twitter) posts in real time.
⏱️ Setup Time: ~3 Minutes
💻 Prerequisites: Node.js (v18+) & Google Chrome
💰 Cost: Free demo mode or ~$0.042 / 1M tokens on Jev
1
Clone the GitHub Repository
Open your terminal and clone the official project repository to your local machine: 
git clone https://github.com/xolotlwastaken/jev-judge.git
cd jev-judge
2
Get Your Jev API Key from OpenRouter
TypeSafe AI's Jev model is hosted on OpenRouter as ~typesafe/jev-latest via their Decisions API. This gives you instant access with zero waitlist:
  1. Navigate to https://openrouter.ai and log in or create a free account.
  2. Go to Keys (https://openrouter.ai/keys) and click Create Key.
  3. Name your key jev-judge and copy the generated key (format: sk-or-v1-...).
  4. (Optional) Add a small credit ($1 to $5) in OpenRouter Settings. At $0.042 per 1M input tokens, $1.00 classifies more than 20,000 tweets!
💡 Offline Demo Mode: Don't have an OpenRouter key yet? No problem! If no key is set, the backend automatically runs in smart Local Demo Mode with simulated classifications so you can test immediately.
3
Configure & Start the Backend Server
The local backend securely handles Jev API calls, tracks token spend, and deduplicates posts with an in-memory cache: 
# 1. Navigate into the server directory and install dependencies
cd server
npm install

# 2. Copy the example configuration to create your .env file
cp .env.example .env
Open server/.env in your code editor and paste your OpenRouter key: 
OPENROUTER_API_KEY=sk-or-v1-your_actual_openrouter_key
PORT=8787
DEBUG=false
Start the backend in development mode: 
npm run dev
✅ Success output: Jev Judge Backend running on http://localhost:8787 · Active Provider: OpenRouter (Jev)

4
Load the Chrome Extension
Install the unpacked extension directly into Google Chrome in just a few clicks:
  1. Open Google Chrome and visit: chrome://extensions
  2. In the top-right corner, toggle Developer mode to ON.
  3. Click the Load unpacked button in the top-left toolbar.
  4. Navigate into your cloned jev-judge directory and select the extension folder.
  5. Jev Judge will immediately appear in your extensions list with its purple diamond icon.
5
Test Live on X (Twitter)
Now experience real-time AI classification as you scroll:
  1. Open https://x.com in Chrome (or refresh any existing X tab).
  2. Look in the bottom-right corner: you'll see the floating JEV HUD Pill: ◆ JEV · 0 judged · $0.00000
  3. Start scrolling! Posts entering your view will briefly display ◆ JEV JUDGING... and resolve in ~200ms.

★
Troubleshooting & Pro Tips
• Badges say "JEV UNAVAILABLE"?
Ensure your backend terminal is running on port 8787. You can check health by running curl http://localhost:8787/health in your terminal.
• Modified extension styles or scripts?
Whenever you make changes to files in extension/, go to chrome://extensions, click the reload icon (↻) on Jev Judge, and hard-refresh X (Cmd + Shift + R).
• Split-Screen YouTube Layout:
Position your browser with X on the left and your terminal running npm run dev on the right. Your audience can watch classifications and micro-penny costs resolve simultaneously as you scroll!
